#### Название проекта

Сервис, использующий YTsaurus

#### Задача

Разработать сервис/приложение, использующее YTsaurus для хранения и обработки данных

#### Суть проблемы

Мы хотим популяризировать YTsaurus. Для этого студентам предлагается сделать какой-нибудь пет проект, в котором будет использоваться YTsaurus. Проект будет размещаться на GitHub, любой желающий сможет его форкнуть. Мы сможем рассказать о нем на ютубе и/или на хабре, чтобы развивать медийность YTsaurus

#### Возможное (готовое) решение

Одна из идей:
 
 Есть открытое API википедии: https://stream.wikimedia.org/v2/stream/recentchange. Там бесконечный поток действий на всех вики-страницах: создание страницы
 
 Также есть открытое API Яндекс Карт: https://yandex.ru/maps-api
 
 Можно сделать сервис, который в режиме real time показывает на карте те места, которые упомянуты в измененных вики-страницах. Под капотом - потоковая обработка данных в YTsaurus
 
 Преимущества:
 
 - Все необходимое - в open source
 - Big data - покажем use case YTsaurus. Можно использовать Spark Streaming для потоковой обработки
 - Связано с еще 1 продуктом Яндекса
