# Локальный запуск

Как поднять WikiPulse на своей машине с нуля, без кластера YTsaurus. Шаги
проверены на чистом клоне; если шаг не работает — это баг документа, а не
твоей машины.

Нужен кластер и настоящий пайплайн — [local-cluster.md](local-cluster.md).
Все переменные окружения одной таблицей — [configuration.md](configuration.md).
Грабли, которые встречались в процессе, — в
[troubleshooting.md](troubleshooting.md).

## Что нужно поставить

| Инструмент | Версия | Зачем |
|---|---|---|
| JDK | 17 | `java.version` в `backend/pom.xml` |
| Node.js | `^20.19` или `>=22.12` | требование Vite 8 |
| pnpm | ставится сам | версия закреплена полем `packageManager` в `frontend/package.json` |
| Ключ Яндекс.Карт API v3 | — | без него карта не отрисуется |

## 1. Бэкенд

```bash
cd backend
SPRING_PROFILES_ACTIVE=mock YMAPS_API_KEY=<ключ> ./mvnw spring-boot:run
```

Поднимается на `http://localhost:8080`.

- **`SPRING_PROFILES_ACTIVE=mock` обязателен.** Профиль по умолчанию —
  `yt` (`spring.profiles.default` в `application.yaml`), а он ходит в кластер
  по RPC, и без кластера бэкенд на нём бесполезен.
- **Больше ничего задавать не нужно.** `YT_PROXY` и `YT_TOKEN` читают только
  `QEnrichedRepository` и `YtAggregatesRepository`, помеченные `@Profile("yt")`;
  на `mock` эти бины не создаются, и плейсхолдеры не резолвятся вовсе.
- **`YMAPS_API_KEY` нужен, чтобы отрисовалась карта.** Где взять ключ и что с
  ним сделать — в [frontend/README.md](../../frontend/README.md). Без ключа
  бэкенд поднимется и данные отдаст, `GET /api/v1/config` вернёт пустую
  строку, а карта покажет экран ошибки.

Проверить, что бэкенд отвечает:

```bash
curl -s "http://localhost:8080/api/v1/hexagons/active?min_lng=37.31&min_lat=55.57&max_lng=37.85&max_lat=55.91&zoom=10"
curl -s "http://localhost:8080/api/v1/dashboard?period=24h&limit=5"
```

Первый запрос отдаёт непустой ответ сразу после старта: `MockPoller` в
`@PostConstruct` заливает в кэш всю выборку целиком. Пустой список `hexagons`
в конкретном прямоугольнике — тоже нормальный ответ: значит, в него не попала
ни одна ячейка выборки.

## 2. Фронтенд

```bash
cd frontend
pnpm install
pnpm dev
```

Открыть `http://localhost:5173/map`.

Dev server проксирует `/api` на `http://localhost:8080`, поэтому бэкенд должен
быть уже поднят. **`pnpm preview` прокси не настраивает** — прокси объявлен
только для `server` в `vite.config.ts`, — так что сквозная проверка
«браузер → `/api` → бэкенд» возможна только на `pnpm dev`; `preview` показывает
прод-сборку и ничего больше.

## 3. Проверки перед ревью

```bash
cd frontend
pnpm test
pnpm lint
pnpm build
```

Бэкенд:

```bash
cd backend
./mvnw verify
```

Профиль здесь задавать не нужно: `backend/src/test/resources/application.yaml`
объявляет `spring.profiles.default: mock`, и тесты идут на нём. Ровно эти
команды выполняет `.github/workflows/ci.yml`.

Полный список команд фронтенда — в [frontend/README.md](../../frontend/README.md).

## Что показывает профиль `mock`

Продукт работает целиком и на настоящих данных: живая карта крутит 730
настоящих правок Википедии, дашборд отдаёт три настоящие витрины. Фикстуры
лежат в `backend/src/main/resources/fixtures/` и сняты через публичный API
боевого стенда 30 августа 2026.

Как это устроено:

- **`MockPoller` воспроизводит снапшот по кругу.** На старте вся выборка
  сдвигается так, чтобы последняя правка легла ровно на «сейчас»: окно
  снапшота (~30 минут) совпадает с окном живой карты, и карта видна сразу, а
  не через полчаса накопления. Дальше раз в 2 секунды та же выборка гоняется
  по кругу с текущим временем; к `id` каждого следующего прохода дописывается
  `#N`, иначе дедупликация по `event_id` отбросила бы повтор.
- **`MockDashboardService` отдаёт фикстуры как есть.** Три файла
  `dashboard-{24h,7d,30d}.json` — настоящие ответы боевого стенда; сервис
  только обрезает топы по `limit`.

Чего профиль `mock` не даёт:

- **Живого потока правок нет.** Выборка конечна и зациклена. Настоящий поток
  читает `YtQueuePoller` из очереди `q_enriched`, для этого нужен профиль `yt`
  и доступ к кластеру.
- **Связь правки с ячейкой синтетическая.** Координат правок в снапшоте нет
  (`dict/coords` через публичный API недоступен), поэтому `MockPoller`
  назначает ячейку по хешу языкового раздела поверх настоящих `h3_parent` из
  `dashboard-24h.json`. Правка настоящая, ячейка настоящая, а вот то, что
  правка сделана именно там, — нет.
- **Числа дашборда не меняются.** Это снимок суток, недели и месяца на дату
  съёмки, а не пересчёт по витринам. Настоящие числа считает
  `YtDashboardService` по `marts/*`.

Требование к хостингу одно: `BrowserRouter` требует отдавать `index.html` на
любой неизвестный путь, иначе прямое открытие `/map` вернёт 404.
